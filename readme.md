# Customer Management System (CMS)

This project implements a data science-driven Customer Management System (CMS) for a commercial organization. It enables customers, customer relationship managers (CRMs), support managers, sales managers, product managers, and loyalty program managers to interact with the system and manage their respective functionalities.

---

## Description

The **Customer Management System** is a web-based application designed to manage customer data for businesses. It provides a comprehensive solution for handling customer details, transactions, feedback, and support interactions. The system aims to enhance customer relationship management by enabling efficient record-keeping, customer satisfaction tracking, and targeted marketing efforts.

---


## Features

### **Customer**
- View personal information
- Update personal information
- View purchases
- Submit support requests
- View support request status
- Submit feedback
- View loyalty points

### **Customer Relationship Manager**
- View customer information
- Add new customers
- Delete customers
- Update customer details
- View customer support requests
- Assign support requests to support managers
- View & respond to customer feedback
- Manage loyalty program (redeem/update points)

### **Support Manager**
- View all support requests
- Update support request statuses
- Generate support reports
- View customer purchases

### **Sales Manager**
- Upload sales data
- Generate sales reports
- View product feedback

### **Product Manager**
- View all products
- Add new products
- Update product details
- Delete products
- Update product categories
- View product feedback

---

## Usage
### Role-based Functionality
- **Customers**: Manage personal information, purchases, and support requests.
- **Customer Relationship Managers**: Handle customer records, feedback, and loyalty programs.
- **Support Managers**: Address support requests and generate reports.
- **Sales Managers**: Upload and analyze sales data.
- **Product Managers**: Manage product catalogs and feedback.

## Technologies Used

- **Programming Language**: Python  
- **Framework**: Streamlit  
- **Database**: MySQL  
- **Libraries**: pandas, datetime

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/AnoopCA/Customer-Management-System.git
   ```

### Running the Application
1. Start the Streamlit application:
   ```bash
   streamlit run main.py
   ```
2. Open your browser and navigate to the displayed local URL.
